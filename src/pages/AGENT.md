# AGENT.md — `src/pages/`

File-based routes. Every page wraps itself in `../layouts/BaseLayout.astro` (which provides head/meta, header, footer, theme, and the scroll-reveal script) except blog posts, which use `PostLayout` (itself built on `BaseLayout`). All pages are prerendered (`output: "static"`).

| File | Route | Layout |
|---|---|---|
| `index.astro` | `/` | BaseLayout |
| `about.astro` | `/about` | BaseLayout |
| `projects/index.astro` | `/projects` | BaseLayout |
| `blog/index.astro` | `/blog` | BaseLayout |
| `blog/[...slug].astro` | `/blog/<slug>` | PostLayout |
| `rss.xml.js` | `/rss.xml` | — (endpoint) |

`sitemap-index.xml` and `robots.txt` are generated by integrations, not pages.

## `rss.xml.js` (31 lines) — `/rss.xml`
- `export const prerender = true` (build-time artifact).
- `GET(context)`: `getCollection("blog", ({ data }) => !data.draft)` sorted by `pubDate` desc; returns `rss({ title: "Jay Boricha — Writing", description: SITE.description, site: context.site, items, customData: "<language>en-us</language>" })`.
- Each item: `title`, `description`, `pubDate`, `link: /blog/<slug>/`, and `content` = full body rendered by `markdown-it` then `sanitize-html` (default allow-list + `img`).
- Requires `site` in `astro.config.mjs` — without it `@astrojs/rss` throws and the route 500s (that was the state before the revamp).
