# AGENT.md — `src/`

All application source. Astro conventions apply: `pages/` are routes, `layouts/` wrap pages, `components/` are `.astro` partials, `content/` is the markdown collection, `styles/` holds the one global stylesheet.

## Files directly in `src/`

### `env.d.ts` (2 lines)
```ts
/// <reference path="../.astro/types.d.ts" />
/// <reference types="astro/client" />
```
Type references only. Stale declarations for Contentful env vars and `*.riv` modules (leftovers from the old template) were removed on 2026-09-14. `.astro/types.d.ts` is generated by Astro and untracked; run `pnpm dev` or `pnpm astro sync` once after cloning so the reference resolves.

## Data flow at a glance
```
content/blog/*.md ──(schema: content/config.ts)──► pages/blog/index.astro ─► components/Blog/PostRow
                                               └─► pages/blog/[...slug].astro ─► layouts/PostLayout ─► layouts/BaseLayout
                                               └─► pages/rss.xml.js
data/projects.ts ──► pages/index.astro (featuredProjects, compact) ─► components/ProjectRow
                 └─► pages/projects/index.astro (all, full)        ─► components/ProjectRow
lib/constants.ts ──► SITE / NAV / SOCIALS / EMAIL / RESUME / LINKS used by layouts, header, footer, contact, hero
styles/global.css ──► imported once in layouts/BaseLayout.astro
uno.config.ts (root) ──► every class name in every .astro file
```

## Where to change what
- Name, URL, email, socials, nav labels → `lib/constants.ts`
- A project → `data/projects.ts`
- Hero / What-I-do copy → `pages/index.astro`
- Bio / expertise / AI section / experience → `pages/about.astro`
- Colours or fonts → `styles/global.css` (values) + `uno.config.ts` (names/scales)
- Meta/OG → `layouts/BaseLayout.astro`
- A blog post → drop a `.md` in `content/blog/`
